# FusioFI Releases

Public downloads for FusioFI firmware and web packages.

This repository is release-only. It does not contain the private source/build project.

## Downloads

Open the latest item in **Releases** and download the ZIP files you need:

- `ESP32.zip` - ESP32 flashing files
- `ESP8226.zip` - ESP8266/NodeMCU flashing files
- `FusionFi_MultiFast.zip` - MultiFast hotspot web package
- `SingleHotpot.zip` - Single Hotpot web/package files

## Notes

- `SingleHotpot` is the folder name used by the package.
- Always use the latest GitHub Release unless you specifically need an older version.
- Firmware binaries are prebuilt; normal users do not need the private source project.
